## Gate interpretation

The local synthetic demo, repository publication, and hosted real-data service are
separate decisions. Passing local unit, contract, fixture, or performance checks
does not satisfy the hosted gate. Publication still requires a reviewed revision,
final evidence links, and the remaining presentation checks.
A hosted synthetic-only demo needs a server-enforced public boundary and
deployment/browser verification. A real-data analytical service additionally needs
human labels/calibration, separate credentials, authenticated evidence
authorization, retention/deletion operations, TLS policy, secret rotation and
incident response.

The current Figma artifact is partial because Starter-plan quota blocked further MCP authoring. Browser verification was prohibited during this audit, so keyboard, responsive, focus, contrast, and design-correspondence acceptance remains manual. No percentage or aggregate readiness score should replace these named gates.
