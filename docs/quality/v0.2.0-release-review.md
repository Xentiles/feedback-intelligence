## Upload security repair

The current-source Codex Security audit found one Low availability issue: eager
allocation preceded structural limits in owner-selected uploads. An independent
boundary review and separate bypass review covered the repair. The latter found
shared-string expansion during child-to-parent JSON transfer; the final patch
conservatively counts every transferred occurrence before output, then checks the
actual retained graph again in the parent.

Parser admission precedes decoding. One fresh subprocess receives only approved
environment settings and has a 30-second wall timeout; Linux Docker applies a
512 MiB address-space cap. Line formats/XLSX rows stream. Scalar JSON preflight,
64 MiB preview/transfer budgets, XML restrictions, four cache slots and borrowed-
preview accounting cover representation/lifecycle changes. Command-envelope
structure/concurrency are also bounded. This is resource isolation within the
trusted local worker authority, not a separate filesystem/network security domain.

Regression cases cover original nested-object amplification, shared-string transfer,
row/column/graph/structure limits, malformed JSON/workbooks, Unicode/escape/line
semantics, ignored worksheet rows, child timeout/reaping, credential environment,
concurrent admission and pinned expiry. A real Linux allocation above the child
ceiling exits safely; a subsequent ordinary parse succeeds. Native macOS does not
claim Linux-equivalent address-space enforcement.
